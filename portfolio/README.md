# Abdelkader Portfolio

Minimal React + Vite portfolio for internship applications.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## First files to customize

- `src/data/portfolioData.js` for all text, links, projects, and skills
- `public/profile-placeholder.svg` for the profile image
- `public/Abdelkader-Ait-Benamara-CV.pdf` for the CV download
- `src/styles/global.css` for colors, spacing, and layout tuning
